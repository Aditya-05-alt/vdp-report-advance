How this works

GA4 (and other tools) report traffic as raw source / medium pairs — google / organic, facebook / paid, autotrader.com / referral, and so on — which is usually too granular to report on directly. Below, map each raw source into a clean channel (the buckets used on the Traffic and Overview tabs). Renaming, merging, or reassigning here updates those tabs immediately. This mapping is shared across all clients; the view counts shown below are for whichever client is selected up top, for context only.

⚠️ Prototype only — not secure

This login system runs entirely in this browser tab: usernames/passwords live in memory, aren't hashed, and reset every time the page reloads. It's here so you can design the account/role structure and click through the dealer experience. Before giving real dealers real logins, this needs a real backend — server-side auth, hashed passwords, sessions, and API-enforced per-dealer data access (a dealer viewing "their" page must be impossible to bypass by editing the page, which is not true today).
